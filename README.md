# admin-newnsb_bookmarklet
It happens often that I know at what date the Federal Councillor has taken a decision, but I don't have the URL for the Press Release (which I need for example for a reference in a text)
The search options in https://www.admin.ch/de/newnsb are extremely clumsy.
So this Bookmarklet is supposed to do something very simple:
- When on the page https://www.admin.ch/de/newnsb, I launch the Bookmarklet
- There is a pop-up asking me for a date, in the DD.MM.YYYY format
- I insert the day I am searching and confirm by clicking OK
- there is know a pop-up asking me to insert one or more keywords (optional)
- I can insert a keyword (optional) and confirm by clicking OK
- I know should get a list of all Press Releases of that day, in the language of my browser (if DE, IT or FR, otherwise EN), with the full title and with a link to the URL
